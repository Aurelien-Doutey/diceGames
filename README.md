# Dice Games

DiceGames est une application web développée avec C# et Blazor, qui regroupe plusieurs jeux de dés accessibles depuis une interface unique.
Le projet a pour objectif de mettre en pratique le développement avec .NET, la création d'interfaces interactives et la programmation de différentes mécaniques de jeu.

## Jeux disponibles

-High Roll : obtenir le meilleur résultat aux dés.

-Pig : accumuler des points en lançant les dés sans prendre trop de risques.

-Yahtzee : réaliser différentes combinaisons pour obtenir le meilleur score.

-Duel : affronter un adversaire dans un jeu de dés.

-Can't Stop : progresser sur un plateau en fonction des résultats des dés.

-Dice Race : participer à une course de dés contre un adversaire.

## Technologies utilisées

C#, .NET 10, Blazor, Razor, HTML, CSS, SVG

## Fonctionnalités

Plusieurs jeux avec leurs propres règles et mécaniques.
Interfaces interactives développées avec Blazor.
Gestion des scores, des tours et des actions des joueurs.
Mode clair et mode sombre.
Interface responsive adaptée aux ordinateurs et aux appareils mobiles.
